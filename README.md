# صيدلية اي براند 3D

جولة ثلاثية الأبعاد في صيدلية اي براند، يتسوق فيها العميل الأقسام والعروض، وكل منتج على الرف يفتح صفحته في ibrand.com.sa.

- `index.html` — الصيدلية (three.js)
- `scripts/build-data.mjs` — يسحب منتجات كل قسم من متجر سلة ويقص صورها ويجمعها في `atlas/`
- `.github/workflows/refresh.yml` — يحدّث المنتجات يومياً تلقائياً، ويمكن تشغيله يدوياً من تبويب Actions
